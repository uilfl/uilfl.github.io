# Getting Started with Astro

Astro is a modern web framework for building fast websites with a focus on content. In this guide, we'll explore the basics and get you up and running.

## Why Astro?

Astro brings several advantages to web development:

1. **Zero JavaScript by default** - Only ship JavaScript when you need it
2. **Island Architecture** - Partial hydration for optimal performance
3. **Framework agnostic** - Use React, Vue, Svelte, or any framework alongside HTML
4. **Built-in optimization** - Image optimization, code splitting, and more

## Installation

Getting started is simple:

```bash
npm create astro@latest my-project
cd my-project
npm run dev
```

## Project Structure

```
src/
├── components/     # Reusable UI components
├── layouts/       # Page layouts
├── pages/         # File-based routing
└── styles/        # Global styles
```
